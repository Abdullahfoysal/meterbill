# Bill Tracker — marketing site

Static landing page for **Bill Tracker: Meter & Usage** (Android), served from this `gh-pages` branch via GitHub Pages at
https://abdullahfoysal.github.io/MeterBillTracker/

- `index.html` — English (default store listing)
- `bn/index.html` — Bangla (Bangladesh store listing)
- `css/`, `js/`, `img/` — assets (icons and screenshots from the Play Store listing)
- `sitemap.xml`, `robots.txt` — SEO

No build step. Edit the HTML and push to `gh-pages`.
